# WearEngine Bridge — состояние проекта

Основные исходники выделены в самостоятельный проект по запросу пользователя.
Лицензия MIT выбрана пользователем. По его запросу история проекта сведена
к одному начальному коммиту, публичная версия начинается с 0.1.
Первичная публикация исходников выполнена по явному запросу пользователя;
теперь он выбрал существующий общий ключ для подписи в GitHub Actions.
Не обращаться к телефону через ADB. Workflow подготовлен для signed APK
из GitHub Secrets; загрузку секретов и запуск выполняет пользователь.
Ключи и пароли остаются внешними; не читать/выводить их и не копировать в проект.

не входят в Git. Релизы не настроены; код подписи в CI подготовлен; пользователь подтвердил настройку Secrets.
